# Bounce Party 🎉

A super simple, fun playground built with **pure HTML + CSS** (no JavaScript!).

- Animated emoji balls bouncing forever
- Color-shifting gradient background
- Confetti that falls when "Party mode" is on (CSS-only checkbox toggle)
- Works in any browser — just open `index.html`

## Try it

Open `index.html` in your browser, or visit the live site:
https://sworddao.github.io/bounce-party/

## Edit it

Everything is in two files:

| File        | What's inside               |
|-------------|-----------------------------|
| `index.html`| Page structure + the emojis |
| `style.css` | All the fun animations      |

Change the emojis in `index.html` or tweak `animation-duration` in `style.css` to make the balls bounce faster or slower.
